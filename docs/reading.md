# 阅读练习

入口：底部或顶部导航的“阅读”（`#/reading`）。

## 根据已学词推荐

- 使用当前词库在本机保存的已学记录，按文章实际覆盖的已学词数量排序。
- 覆盖量相同时，优先覆盖错词，再优先未读文章。匹配统计包含原形及常见词形变化，不表示已经掌握该词在所有语境中的用法。
- 内置 6 篇约 300 词的原创短篇，覆盖教育、文化、城市、职场、科学和历史话题。难度分为 B1、B2、C1，标签为练习分级。
- 没有已学记录时可体验阅读；若记录在其他设备上，请先在“我的”中导入该设备的学习备份。

每篇包含 3 道 TRUE / FALSE / NOT GIVEN、2 道四选一和 1 道原文填空。提交后显示得分、中文解析及原文依据。NOT GIVEN 的引用是相关上下文，不代表原文已经提供了题干所需信息。

## 用已学词准备新文章

1. 展开书架下方的“用自己的已学词，准备一篇新文章”。
2. 选择难度并复制提示词。最多包含 40 个词，优先错词及最近学过的词。
3. 将提示词粘贴到自己使用的 AI 对话中。
4. 把返回的完整 JSON 粘贴导入，或选择 JSON 文件。

导入支持 150–1,000 词、3–8 段、3–12 题的短文，最多保存 10 篇自定义文章。会校验题目格式、答案格式及引用是否位于指定段落；不能自动证明题意和答案正确，请核对 AI 生成内容。

## 数据与费用

阅读推荐、做题和判分均在浏览器本地运行，兼容 GitHub Pages，不需要后端或 API Key。复制提示词不会自动调用 AI；没有后台自动生成文章的服务。

答题草稿、成绩和自定义文章均随现有“导出备份”保存。导入旧版学习备份仍会保留其中的单词记录。阅读不改变单词的 FSRS 调度、答题正确率或每日新词数。

这些是原创短篇练习，不是官方雅思真题，也不将短篇得分换算为雅思分数。题型说明可参考 [IELTS Academic Reading 官方页面](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)。
