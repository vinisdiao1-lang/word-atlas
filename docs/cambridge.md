# 剑桥雅思阅读训练

入口：阅读 → 剑桥真题 11–19（`#/cambridge`）。

## 直接使用

网站已经内置剑11–19文字版：进入阅读训练即可选择文章或开始模考，无需传文件、解压或手动导入。文章按段落排版，题干、选项、Heading列表和Summary均为可选择的网页文字；独立题目旁直接填写答案，判断题支持点选。原卷图片折叠在“核对原卷图片”内，用于核查提取差异，不作为默认阅读方式。

根据用户要求，提取后的阅读内容、题目和答案随公开网站一起部署。原始整本PDF与提取缓存仍留在本机。保留“导入训练备份 / 本地题库”以恢复记录或覆盖某册本地题库；本地导入文件不会上传到网站。

## 三阶段规则（剑11–18）

| 阶段 | 文章来源  | 只练这些题型                                           | 达标最低答对数         |
| ---- | --------- | ------------------------------------------------------ | ---------------------- |
| 1    | Passage 1 | 选择、判断（TRUE/FALSE/NOT GIVEN 或 YES/NO/NOT GIVEN） | ceil(实际题数 × 11/13) |
| 2    | Passage 2 | Heading、段落信息匹配                                  | ceil(实际题数 × 10/13) |
| 3    | Passage 3 | Summary、选择                                          | ceil(实际题数 × 8/14)  |

每次练习保留单篇原卷题号，不补题、不跨文章拼题。完成一次达标练习即可解锁下一阶段，可随时回练已解锁阶段。人物/日期/理论匹配、句子结尾匹配不冒充选择题。没有目标题型的文章不会出现在当前阶段。

可选“只看包含已背单词的文章”：读取当前设备的单词学习记录，按文章和题目原页中的词汇原形匹配，优先匹配更多已学词。关闭后按原书顺序展示。

T1–T4 表示上传文件内的第1–4套。剑12学术类对应原书Test5–8，原页编号保留原样。

## 剑19完整阅读模拟

四套各含三篇、40题，保持原卷顺序，不进行已背词筛选。可选60分钟计时或不计时。计时从开始时起连续计算，刷新、切换页面、关闭后重开都不暂停；超时自动交卷。模拟不换算雅思分数。

## 判分和复盘

支持大小写、NOT GIVEN 空格、可选词、常见英美拼写与原书标注的多选任意顺序。重复多选字母不重复得分。OCR或文本层仍可能有误，可展开原始答案页逐项核对，并人工校正判分。未可靠识别的答案保留待核对，不凭空编造解题解析。

错题复盘保存答案、人工核对结果和笔记。建议记录原文页码/段落、同义改写、错因与下次策略。

“导出训练记录”包含草稿、截止时间、成绩与笔记，不包含书籍原页；导入会合并不同练习，重复ID采用导入版本。记录与单词学习备份分开管理。换设备只需恢复训练记录，网站题库会自动加载。清理浏览器数据可能删除本机导入题库和记录。

## 本地提取维护

- `scripts/cambridge/ocr.swift`：使用 macOS PDFKit + Vision 做本机 OCR。
- `scripts/cambridge/extract.py`：构建私人题库和阅读PDF；需要PyMuPDF，缓存放`.local/cambridge`。
- `node scripts/cambridge/publish.mjs`：把提取结果拆成`public/cambridge/v1/library.json`与共享JPEG原页，供网站自动加载。普通构建直接使用已提交的静态资源，不依赖本地PDF或OCR环境。
- `text.py`、`finalize_text.py`：结合PDF文字层和本机OCR位置还原双栏顺序、段落与题号，输出文字版`public/cambridge/v2/library.json`。扫描识别仍可能有差异，可用折叠原页核对。
- 扫描文字提取与答案原页核对结果均保存在私人缓存，未提交到Git。

原文阅读时长、题量说明：[IELTS Academic Reading](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)。
